# NASSAR Accounting — Android starter

This is a **prototype shell only**, not an accounting system. The screen contains nonfunctional navigation placeholders. No database, sync, invoices, security, or printing is implemented yet.

## Build
GitHub Actions > Build Android APK > Run workflow. Download the `NassarAccounting-debug-APK` artifact.

## Important
- Debug APK is **not** a release build. For production updates use a permanent, protected release signing key and increment versionCode.
- `com.nassar.accounting` is a provisional application ID; finalize it before distribution.
- Official icon/logo asset is **not yet included**. Use the exact approved source image later.
- No credentials, customer data, or signing keys belong in a public repository.
